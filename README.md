# maze-test-plugin

Claude Code plugin: `/maze-test` — generates copy-paste-ready Maze unmoderated usability test scripts for Delivery Hero CPL designers (Pricing, Choice, Seamless domains).

## Install

```
/plugin marketplace add <owner>/maze-test-plugin
/plugin install maze-test@maze-test-marketplace
```

## Use

```
/maze-test:maze-test
```

Choice and Seamless designers: before running the command, fill in the `[To be defined]` rows in the Domain Context table in `commands/maze-test.md` with your product name, user personas, and scenario framing.
